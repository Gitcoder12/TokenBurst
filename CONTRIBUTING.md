# Contributing to TokenBurst

1. Read README.md, FEATURE_UPGRADE_PLAN.md and ACTIVITY_LOG.md.
2. Check the current CLI and source path before editing examples.
3. Work on a feature branch and change one bounded behavior.
4. Add token-level correctness fixtures and malformed-input tests.
5. Benchmark with fixed data and documented compiler/hardware settings.
6. Report all failed and unrun tests honestly.
7. Open a PR with exact commands and measured evidence.

Do not publish unverified performance claims or describe an isolated CUDA kernel as an integrated GPU tokenizer. Human maintainers approve merges/releases.
